# Art Direction

## Стиль

Чистая спокойная mobile puzzle эстетика: светлый фон, контрастные числовые плитки, аккуратная линия выбора, минимум декоративных элементов.

After the 14 June 2026 UI refresh, the recognizable visual language is a quiet coordinate-paper background, route-cockpit home panel, snake-map level picker, large readable number tiles, warm-gold connected paths, waypoint order badges and a real board/score crop in store creatives.

The current gameplay direction emphasizes a route dashboard instead of a generic score card: a dark target panel, animated progress rail, live selected-value trace and subtle value-weight marks on idle tiles make the core loop feel more proprietary while staying calm and readable.

## Палитра

- Primary: deep leaf green.
- Accent: warm gold.
- Support: restrained blue and clay.
- Background: soft mist/off-white.
- Error: clear red.

## Правила

- Не использовать случайные иллюстрации, персонажей, псевдо-3D, блики, неон и fake UI.
- Текст должен быть live UI text, не нарисованный в картинке.
- App icon должна читаться в маленьком размере и не содержать мелкий текст.
- В финальной иконке не должно быть текста/цифр, пугающего настроения или техничного вида.
- Feature graphic должен строиться на реальном UI/screenshot или качественной композиции, не на шаблонной картинке.

## Хороший результат

Минималистичная, взрослая, спокойная головоломка с крупными числами, ясной целью и мягким feedback.

Финальная иконка: сгенерированный raster icon с мягкими плитками и золотой линией на зелёном фоне, без текста и персонажей; Play icon, Android launcher, splash and onboarding brand mark use the same cleaned full-square 512x512 PNG with opaque alpha.

## Плохой результат

Перегруженный баннер, случайный маскот, мелкий текст, фейковые карточки, неоновые линии ради декора, дешёвый AI-арт.
