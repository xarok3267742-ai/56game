# Release Report

## Выбранная идея

«Линия 56» - offline-first числовая головоломка для русскоязычной casual-аудитории. Идея выбрана за простую механику, низкий Google Play риск и возможность сделать аккуратный mobile UI без backend и персональных данных.

## Реализовано

- Нативный Android проект Kotlin + Jetpack Compose.
- Нейтральный `applicationId`: `com.qgrid.mobile`.
- 36 deterministic уровней с гарантированным решением на сумму 56 and independent solver reachability coverage.
- Game model validation rejects inconsistent cell positions, non-positive values, board sizes outside the readable 4x4-6x6 release range, level ids outside the released set, mismatched level/board sizes, invalid canonical solution paths and inconsistent `GameState` status/selection/playable hint metadata before game logic can read them.
- Игровой reducer: select, repeated-cell rejection, adjacency check, exceeded state lock, undo, reset, current-selection-aware hint with repair feedback, win and immutable post-win state.
- Reducer input hardening rejects coordinates outside the current board without mutating the path or crashing.
- Экраны: onboarding, home, levels, game, settings, about/privacy.
- Result panel keeps a clear post-win action: `Следующий уровень` appears only when a higher available level id exists; otherwise the action is `К уровням`; the next action resolves from the won `gameState.level` rather than a stale `currentLevel`.
- Локальное сохранение progress/settings через DataStore with corrupted-progress normalization, including malformed completed-level CSV handling.
- Русские строки, no ads, no analytics, no payments, no `INTERNET`, no dangerous/platform runtime permissions.
- Android backup disabled with `android:allowBackup="false"` so local progress/settings are not included in cloud backup or device restore.
- Manifest entry-point hygiene is verifier-gated: source manifest declares exactly one launcher activity (`.MainActivity`, `exported=true`, MAIN/LAUNCHER) and no services, receivers or providers.
- Release-ready ImageGen raster launcher icon with adaptive and monochrome themed-icon support.
- Google Play store icon created and verified against Play dimensions/formats.
- Feature graphic concept archived as `play_store/archive/feature_graphic_concept.png` and rejected for release upload after visual audit.
