# Google Play Listing - RU

## App Name

Линия 56

## Short Description

Проводите линию по числам и соберите ровно 56

## Full Description

«Линия 56» - спокойная числовая головоломка без интернета.

На каждом уровне есть поле с числами. Соединяйте соседние клетки одной непрерывной линией: по горизонтали, вертикали или диагонали. Задача - набрать точную сумму 56. Если сумма стала больше, отмените ход или начните маршрут заново.

Игра сделана для коротких аккуратных сессий: без таймера, рекламы и лишних отвлечений. Текущая сумма всегда перед глазами, а подсказка помогает найти следующий шаг, если маршрут зашел в тупик.

В версии 1.0:

- 36 коротких уровней;
- движение по соседним клеткам в 8 направлениях;
- подсказка, отмена хода и сброс линии;
- понятный результат после победы;
- сохранение прогресса на устройстве;
- настройки тактильного отклика, контраста и уменьшения движения;
- без рекламы, аккаунтов, платежей, аналитики и обязательного интернета.

«Линия 56» подходит для спокойной тренировки внимания, счета и планирования на несколько минут в день.
