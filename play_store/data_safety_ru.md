# Google Play Data Safety Notes

## Data Collection

Данные пользователя не собираются.

## Data Sharing

Данные не передаются третьим лицам.

## Local Data

На устройстве локально сохраняются:

- прохождение onboarding;
- список пройденных уровней;
- последний открытый уровень;
- настройки тактильного отклика, контраста и уменьшения движения.

Эти данные не покидают устройство и не используются для идентификации пользователя. Android backup для приложения отключён, поэтому локальный progress/settings не включаются в cloud backup или device restore.

## Security

Нет сетевой передачи пользовательских данных. Manifest не запрашивает `INTERNET` или `ACCESS_NETWORK_STATE`. Нет аккаунтов, аналитики, рекламы, платежей, crash reporting SDK или device identifiers.

## Deletion

Локальные данные удаляются штатным действием Android: удаление приложения или очистка данных приложения в настройках устройства.
